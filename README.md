## GitHub Pages
Upload alle bestanden en mappen in deze map naar de root van je repository `ict-portfolio`.

Belangrijk:
- `index.html`, `styles.css` en `script.js` moeten in de root staan.
- Laat de map `assets` staan zoals hij is.
- GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
