`assets/cv/cv-hendrik.pdf`

## Publiceren op GitHub Pages

1. Maak op GitHub een nieuwe repository, bijvoorbeeld `ict-portfolio`.
2. Upload alle bestanden uit deze map.
3. Ga naar **Settings → Pages**.
4. Kies bij **Build and deployment** voor **Deploy from a branch**.
5. Selecteer `main` en `/ (root)`.
6. Sla op. GitHub geeft daarna je openbare websiteadres.
